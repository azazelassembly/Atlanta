# Atlanta OS

Atlanta is a distribution based on Fractions OS with a completely unique kernel, designed to ensure stability, security, and performance.

## Features
- **Unique Kernel:** A fully independently developed kernel provides flexibility and high performance.
- **Security:** Advanced protection mechanisms against external threats.
- **Modularity:** Easily configurable system components.
- **Support for Modern Technologies:** Optimized for the latest hardware.
